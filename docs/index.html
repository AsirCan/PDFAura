Geliştiriciler & Sistem Yöneticileri

Terminalden Tam Kontrol: PDF Aura CLI

Arayüz açmadan betiklerinizde veya PowerShell üzerinden PDF Aura gücünden yararlanın.

# 1. PDF Sıkıştırma (ebook / screen / printer / prepress) $ python -m src.cli compress buyuk_dosya.pdf -q ebook -o kucuk_dosya.pdf # 2. Belirli sayfaları bölme $ python -m src.cli split katalog.pdf --pages 1-10 -o bolum1.pdf # 3. Çoklu PDF dosyalarını birleştirme $ python -m src.cli merge rapor1.pdf rapor2.pdf rapor3.pdf -o birlesik_rapor.pdf # 4. Askeri düzey AES-256 şifreleme $ python -m src.cli encrypt sozlesme.pdf -p GizliSifre2026 -o guvenli.pdf # 5. Filigran ekleme (açı, şeffaflık ve font boyutuyla) $ python -m src.cli watermark taslak.pdf -t "KORUMALI BELGE" --opacity 0.25 -o filigranli.pdf

Sıkça Sorulan Sorular

PDF Aura hakkında en çok yöneltilen soruların yanıtları.

Evet. PDF Aura'nın mimari temeli "Offline-First" ve "Privacy-First" olarak inşa edilmiştir. Dosyalarınız, görselleriniz ve belgeleriniz asla uzak bir sunucuya yüklenmez veya internete sızdırılmaz.
Hayır. PDF Aura kendi bünyesindeki yerel dil modellerini (GGUF formatında Qwen, Mistral vb.) doğrudan bilgisayarınızda çalıştırır. Herhangi bir harici API anahtarı, kredi kartı veya aylık abonelik gerekmez.
PDF Aura şu an Windows 10 ve Windows 11 (64-bit) işletim sistemleriyle tam uyumludur. Hem kurulum yapılabilen (.exe) hem de taşınabilir (portable .zip) sürümleri mevcuttur.
Hayır. Tüm dönüştürme, sıkıştırma, OCR ve yapay zeka işlemleri arka plan iş parçacıklarında (background tasks) çalıştırılır. İşlem süresince arayüz akıcı kalır, ilerleme yüzdesi anlık gösterilir ve istenildiği an iptal edilebilir.
Evet. PDF Aura yüzeysel olarak siyah kutu çizmekle yetinmez; "True Redaction" ilkesiyle sansürlenen metni ve piksel verisini PDF'in ham dosya baytlarından kalıcı olarak söker. Metin seçme veya arama araçlarıyla geri döndürülemez.
Kesinlikle. python -m src.cli veya pdfaura komutu ile sıkıştırma, birleştirme, bölme, döndürme, şifreleme ve resme dönüştürme gibi tüm araçları PowerShell, CMD veya bash betiklerinizde otomatikleştirebilirsiniz.
